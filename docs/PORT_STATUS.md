# C 포트 상태

## 현재 플레이 범위

메뉴에서 1인, 2인 협동 플레이 또는 순위표를 선택합니다. 초록 1P와 파랑 2P는 각자의 키보드 배치와 게임패드로 이동, 점프하고 거품을 발사합니다. 2인 모드에서 2P 발사는 Right Shift입니다. [참고 저장소 main의 커밋 `5ea6398`](https://github.com/luvxxxu/BubbleBobble/tree/5ea63987d393d9f3c811a5b129f453d08e599bd0)을 기준으로 다음 규칙을 복원했습니다.

- ZenChan·Maita·Monsta의 이동과 공격, 거품 포획·탈출·처치, Maita의 바위 투척.
- 서로 다른 다섯 라운드와 기본 폭에서 라운드별 1·2·3·4·5마리의 적, 7초 클리어 대기와 최종 승리.
- 음식 20종의 드롭과 습득 점수, 플레이어별 생명 5개, 사망·부활·무적, 전원 탈락 시 게임 오버.
- 플레이어별 이니셜 입력과 상위 10개 기록의 저장·표시. 저장 실패 재시도와 기존 파일 보호.

각 라운드는 공중 발판 다섯 개, 측면 벽과 바닥 순환 통로를 갖습니다. 다른 플레이어가 포획한 적도 터뜨릴 수 있으며, 음식 점수는 실제로 먹은 한 사람만 받습니다. 2인 모드의 마지막 생명을 잃으면 1.5초 사망 연출 뒤 큰 부활 버블이 됩니다. 버블은 동료를 추적하지 않고 별도 난수 상태로 1~1.8초마다 방향·속도를 정해 둥둥 떠다닙니다. 화면 경계에서 안쪽으로 반사되며 공중 발판에 걸리지 않습니다.

부활 버블 생성 후 10초 안에 살아 있는 동료가 접촉하거나 빈 발사 버블로 터뜨리면 그 자리에서 생명 1개와 3초 무적으로 돌아옵니다. 남은 시간을 HELP 표시 옆에 보여 줍니다. 제한 시간이 끝나면 버블이 사라져 다음 라운드를 기다리고, 그동안 접촉·발사로 구조하거나 조작·아이템 획득을 할 수 없습니다. 다음 라운드가 시작되면 시작 위치에서 생명 1개와 3초 무적으로 자동 부활합니다. 점수·마나는 보존하고 구조·라운드 대기 중에는 마나를 진행하지 않습니다. 아직 구조 가능한 버블은 라운드·화면 크기가 바뀌어도 남은 시간과 무작위 경로를 유지합니다. 일반 64개 발사 버블 배열과 독립적입니다. 모두 생명을 소진하면 사망 연출 뒤 게임 오버이며 대기자만 남아서 진행이 멈추지 않습니다. 1인 모드와 생명이 남아 있는 플레이어의 자동 부활은 유지합니다. 원본 아트는 보존합니다.

공중 발판 다섯 개는 라운드마다 각각 초당 1.5 이상 3 미만 타일의 무작위 속도를 정합니다. 원래 위치에서 좌우 `1 + (현재 맵 폭 - 32) / 2`타일 범위로 독립적으로 왕복하되, 각 발판의 길이를 고려해 벽 안쪽으로 제한합니다. 기본 폭에서는 이전과 같은 좌우 한 타일이고, 전체 화면에서 넓어진 영역을 더 멀리 이동합니다. 한 발판의 연속 블록은 같이 움직입니다. 플레이어·몬스터·음식은 서 있는 발판과 함께 이동하고, 점프하면 운반에서 빠집니다. 화면 축소로 발판 범위를 보정할 때도 실제 탑승자만 함께 옮깁니다. 맨 아래 바닥과 벽은 고정됩니다. 빈 거품은 발사 후 8초, 포획한 거품은 발사 후 13초가 지나면 자연 파열하며, 포획 시 남은 시간에 기존보다 5초가 추가됩니다.

각 발판의 소멸 예고 전 유지 시간은 1~5라운드 순서로 20~22초, 16.5~18.5초, 13~15초, 9.5~11.5초, 6~8초입니다. 시간이 지나도 순서를 기다리며, 다음 소멸 예고까지의 최소 간격도 라운드별 8·6.5·5·3.5·2초로 줄어듭니다. 소멸 예고부터 재생성까지의 발판 수는 라운드별 1·1·2·2·3개로 제한해 다섯 발판 중 최소 두 개를 항상 정상 표시합니다. 유지 시간이 지난 발판 중에서 소멸을 시작할 때마다 하나를 무작위로 고릅니다. 고정 순서로 순환하지 않으며, 대기 중에는 추첨하지 않습니다.

소멸 예고 1.2초, 부재 3초, 생성 예고 1.2초는 모든 라운드에서 같습니다. 두 예고 모두 전체 발판의 점선 테두리를 0.2초 표시·0.2초 숨김으로 세 번 깜빡입니다. 소멸 예고 중에는 밟을 수 있고, 사라지는 틱에 탑승자의 지지를 해제합니다. 생성 예고 중에는 충돌하지 않고, 생성된 뒤에도 아래에서 점프해 통과할 수 있습니다. 좌우 이동은 모든 단계에서 계속되고, 메뉴·인트로·결과 화면이나 일시 정지 중에는 이동과 단계 시간이 함께 멈춥니다.

창 크기와 Retina 배율을 반영한 실제 해상도에 렌더 타깃을 맞춥니다. 모든 그림에는 공통 배율을 적용하고, 여분의 공간은 실제 이동 가능한 맵의 열·행으로 확장합니다. 원본 발판 배치는 중앙·바닥 기준으로 유지하며 벽과 바닥은 확장된 경계를 따릅니다. 크기가 바뀌어도 게임 진행과 발판의 속도·생성 단계를 유지합니다. HUD는 화면 가장자리에 표시하고 F11은 모니터 해상도를 바꾸지 않는 테두리 없는 전체 화면을 사용합니다. 일반 실행의 난수 시드는 실행 시각에서 얻고 스모크 테스트는 고정 시드를 사용합니다.

플레이어의 좌우 이동과 공중 관성에만 현재 맵 폭/32의 배율을 적용하며 마나 가속은 그 결과를 두 배로 만듭니다. 점프·낙하와 몬스터·발판·투사체의 속도는 유지합니다. 몬스터 수는 라운드 기본 마릿수에 같은 폭 배율을 곱해 올림합니다. 플레이 중 확대하면 추가분을 즉시 생성하며, 현재 라운드에서 이미 생성한 수를 기억해 축소 후 재확대로 처치한 적이 부활하지 않게 합니다. 축소해도 기존 적을 제거하지 않고, 클리어 대기 중에는 증원하지 않습니다. 최대 폭 256타일의 마지막 라운드에는 40마리가 등장합니다.

각 플레이어의 마나는 15초 충전과 5초 가속을 반복합니다. 저장 상태와 계산이 독립적이며, 1인 모드의 2P는 갱신하지 않습니다. 게임을 새로 시작하면 두 사람의 마나와 발사 대기시간, 거품을 초기화합니다. 메뉴·인트로·결과 화면·사망 대기·구조 대기·다음 라운드 대기·탈락·일시 정지·창 포커스 상실 중에는 마나가 진행되지 않습니다. 부활이나 다음 라운드에서는 남은 마나와 점수를 유지합니다.

## 코드 구조

입문용 테트리스 코드의 배열·구조체·반복문·조건문 구성에 맞춰 삼항 연산자와 중첩 구조체 초기화를 풀었습니다. 위치·속도·상태를 한 항목씩 대입하고, 렌더링은 타일·적·버블·아이템·플레이어 순서의 함수로 나눕니다. 헤더의 상태·필드, 함수와 처리 단계에 한국어 설명을 보강했습니다. 기존 게임 규칙과 계산 순서는 유지합니다.

게임 로직은 고정 배열, 간단한 구조체, 일반 함수, 조건문과 반복문으로 구성합니다. 충돌 백엔드 함수 포인터와 이벤트 비트마스크를 제거했습니다. `bb_game_update` 한 번으로 발판, 플레이어, 적, 거품, 바위, 아이템, 접촉 판정과 진행 상태를 순서대로 처리하므로 호출자가 별도 충돌 함수를 호출할 필요가 없습니다. 마나는 `update_mana`에서 한 사람씩 계산하고, 충돌과 소리 발생 여부는 이름이 있는 참/거짓 필드로 표시합니다.

그래픽·입력·소리는 Raylib 5.5를 계속 사용합니다. 게임 규칙의 회귀 테스트는 창 없이 실행됩니다. 고정 시간 갱신, 배열 범위 검사, UTF-8 경로 처리와 자원 정리는 유지합니다. 게임 규칙에는 동적 메모리 할당이 없습니다.

2P의 발사·부유·파열·포획 버블은 파란색입니다. 녹색이 들어 있는 원본 그림은 로드할 때 2P용 복사본을 만들고, 포획 그림은 버블 테두리만 바꿔 적의 몸과 눈 색을 보존합니다. 흰색 큰 버블은 2P일 때 파랑을 곱해 부활·파열·시작 연출에 사용합니다. 1P 그림과 원본 이미지 파일은 그대로입니다.
