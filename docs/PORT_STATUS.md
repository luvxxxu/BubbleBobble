# C 포트 상태 — 단일 레벨 테스트 브랜치

## 현재 플레이 범위

한 명의 플레이어가 한 레벨에서 이동, 점프와 거품 발사를 시험할 수 있습니다. 레벨에는 공중 발판 다섯 개, 측면 벽과 바닥 순환 구멍이 있습니다. 적과 아이템, 점수, 생명, 클리어 판정, 다음 레벨 및 종료 화면은 이 브랜치의 게임 규칙에서 제거했습니다. 원본 적·아이템 아트는 참고 자료로 보존합니다.

에너지는 플레이 중 15초 충전과 5초 가속을 반복합니다. 게임을 새로 시작하면 초기화됩니다. 메뉴·인트로·일시 정지·창 포커스 상실 중에는 시뮬레이션 시간이 진행되지 않습니다. 이전 기능을 포함한 이식 기록은 Git 기록에서 확인할 수 있으며, 이전 브랜치의 검증 결과를 이 구성의 검증 결과로 간주하지 않습니다.

## 검증 범위

그래픽 의존성이 없는 C11 테스트는 단일 맵의 발판 도달성, 플레이어 이동·충돌·순환, 거품의 수명과 충돌, 에너지 경계, 유한 입력 처리 및 결정적인 장시간 실행을 확인합니다. 플랫폼 테스트는 에셋 경로, 크기 제한 경로 연결, UTF-8 파일 열기와 명령줄 인수 처리를 검사합니다. 디코더 테스트는 WAV·OGG 에셋을 장치 없이 검사합니다. 실행 명령은 [빌드 안내](BUILD.md)를 참고하세요.

2026-09-30 이 브랜치에서 headless, sanitizer 및 macOS arm64 구성의 CTest를 각각 5/5 통과했습니다. macOS 에셋 검증과 900프레임 / 1,800틱 스모크 실행도 통과했고, 종료 화면은 레벨 1 플레이 상태였으며 캡처에 적·아이템이 없음을 확인했습니다. Windows x86/x64는 LLVM-MinGW 교차 빌드가 성공했습니다.

수동 입력·오디오와 Windows 장치의 그래픽·오디오·입력은 별도 확인이 필요합니다. macOS 로컬 빌드와 교차 컴파일만으로 Windows 실행 동작을 확인했다고 볼 수 없습니다. VS2010 솔루션도 해당 IDE와 Windows 환경에서 직접 빌드·실행해야 합니다.

## 알려진 범위와 다음 검증

1. **Windows x86/x64를 Windows에서 실행:** 제공한 MSVC 프리셋으로 테스트와 게임을 실행하고 화면 배율, 창 크기 변경, 키보드·게임패드 입력, 오디오 장치 손실 및 비ASCII 에셋 경로를 확인합니다.
2. **원본과 물리 동작 비교:** C 타일 충돌 해석기의 관성, 일방 통과 발판 접촉 및 거품 탑승을 실제 플레이와 녹화로 비교합니다. 거품끼리의 물리 충돌과 플레이어 이외 힘에 따른 파열은 단순화되어 있습니다.
3. **수동 장시간 플레이:** 한 레벨에서 이동, 점프, 화면 순환, 거품 파열, 에너지 주기를 반복하며 시간 경과만으로 플레이 상태가 끝나지 않는지 확인합니다.
4. **배포 패키지 검증:** Windows 출력은 콘솔 실행 파일이고 macOS 앱은 서명되지 않은 로컬 번들입니다. 설치 관리자, 서명·공증 및 최종 배포 환경 검증은 별도로 필요합니다.
